# 캠핑 요리 레시피 데이터

봇이 참고하는 기본 레시피 모음. 각 레시피는 **메뉴 → 재료 → 조리법** 구조.
여기 없는 메뉴는 전문가 지식으로 생성해서 답한다.

---

## 1. 불 멍 삼겹살 (2~4인 / 숯불·화로대 / 간단)

**재료**
- 삼겹살 600g, 대파 2대, 마늘 1줌, 쌈채소 1봉
- 양념: 쌈장, 소금·후추, 기름장 (소금+참기름+후추)
- (선택) 김치, 콩나물국 컵

**조리법**
1. 숯에 불 붙이고 흰 재가 덮일 때까지 15~20분 기다린다 (성급하면 그을음만 묻음).
2. 석쇠를 5분 예열 후 삼겹살을 올린다. 자주 뒤집지 말고 한 면당 3~4분.
3. 기름이 떨어지며 불이 확 올라오면 가장자리로 옮겨 탄화 방지.
4. 노릇해지면 가위로 잘라 한 입 크기로. 대파·마늘도 같이 구워 곁들임.

**꿀팁**: 화로대 한쪽은 강불, 한쪽은 약불 존으로 나누면 굽기 조절이 쉽다.

---

## 2. 캠핑 김치찌개 (2~4인 / 버너 1구 / 보통)

**재료**
- 묵은지 1/4포기, 돼지목살 300g, 두부 1/2모, 대파 1대, 양파 1/2개
- 양념: 고춧가루 1큰술, 다진마늘 1큰술, 국간장 1큰술, 설탕 약간

**조리법**
1. 코펠에 기름 두르고 목살·김치를 중불에 5분 볶는다 (감칠맛의 핵심).
2. 물 500ml + 고춧가루·마늘 넣고 끓인다.
3. 끓으면 양파·두부 넣고 10분 더. 간은 국간장으로 맞춘다.
4. 마지막에 대파 넣고 1분.

**꿀팁**: 김치를 집에서 한 번 볶아 지퍼백에 담아 가면 현장 시간 절반.

---

## 3. 백패킹 알리오 올리오 (1~2인 / 버너 1구 / 간단·경량)

**재료**
- 스파게티 면 180g, 올리브유, 마늘 5쪽(편), 페페론치노 3개, 소금
- (선택) 베이컨, 파슬리가루

**조리법**
1. 물 끓여 면을 1분 덜 삶는다 (면수 한 컵 남길 것).
2. 다른 버너/식은 후 올리브유에 마늘·페페론치노 약불로 향 낸다.
3. 면 + 면수 조금 넣고 강불로 30초 비벼 유화시킨다.
4. 소금으로 간. 베이컨 있으면 2단계에서 같이.

**꿀팁**: 면을 집에서 반 삶아 식혀 가면 연료·시간 절약. 백패킹은 무게=연료.

---

## 4. 화로대 대패 차돌된장 (2~4인 / 화로대·버너 / 보통)

**재료**
- 차돌박이 300g, 양파 1개, 청양고추 2개, 알배추 1/4통
- 양념: 된장 2큰술, 고추장 1큰술, 다진마늘, 미림 약간

**조리법**
1. 무쇠팬·불판 달군 뒤 차돌을 펴서 굽는다 (기름 안 둘러도 됨).
2. 기름 나오면 양파·배추 넣고 숨 죽인다.
3. 된장·고추장 양념을 가장자리에서 살짝 볶아 향 낸 뒤 섞는다.
4. 청양고추로 칼칼하게 마무리. 밥·쌈에 곁들임.

**꿀팁**: 무쇠팬은 식기 전에 키친타월로 닦으면 설거지 거의 없음.

---

## 5. 불멍 안주 3종 (2~4인 / 숯불 / 간단)

**재료**
- 통마늘·꽈리고추, 버터구이 새우, 치즈 떡꼬치
- 버터, 소금, 꿀, 떡·소시지·슬라이스치즈

**조리법**
1. **버터 통마늘**: 호일에 마늘+버터+소금, 약불 가장자리에서 15분 익힘.
2. **버터 새우**: 새우를 호일 팬에 버터·소금으로 5분.
3. **치즈 떡꼬치**: 떡·소시지 꼬치 구운 뒤 치즈 올려 녹임, 꿀 살짝.

**꿀팁**: 호일 팬을 쓰면 불멍 보면서 천천히 익히기 좋고 설거지 0.

## 메뉴 빠른 인덱스

| 상황 | 추천 |
|------|------|
| 1인 백패킹 (경량) | 알리오 올리오, 라면+α |
| 2~4인 가족 | 김치찌개, 차돌된장, 삼겹살 |
| 불멍·술안주 | 불멍 안주 3종, 버터구이 |
| 숯불·화로대 | 삼겹살, 차돌된장 |
| 추운 겨울 | 김치찌개, 어묵탕, 된장찌개 |
| 더운 여름 | 냉파스타, 오이냉국, 물회 |
